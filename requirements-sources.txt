# Source pins for non-PyPI dependencies.
#
# daedalus's `techne` extra depends on techne (distribution `tenish-techne`), which is not published to a public
# index (the name "techne" on PyPI is an unrelated package). This file supplies the
# concrete git source so the extra installs on a clean machine, given credentials
# for the private repo.
#
#   Non-dev install with memory:
#       pip install -r requirements-sources.txt ".[techne]"
#
#   Dev keeps an editable sibling checkout instead (live local edits):
#       pip install -e ../techne
#
# Bump the pinned tag when consumers should pick up a new techne release, and lift
# the matching `tenish-techne>=X` floor in pyproject.toml's `techne` extra so the abstract
# floor and the concrete pin stay in step.
